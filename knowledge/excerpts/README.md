# Auszüge

Hier liegen Textauszüge aus Reglementen, eine Datei pro Dokument.

Dateiname: `herausgeber-dokument-jahr.md`, zum Beispiel `swissunihockey-lizenzreglement-2026.md`.

Kopf jeder Datei:

```
Quelle: (Dokumenttitel)
Herausgeber: (Verband)
Link: (URL)
Stand/Gültig ab: (Datum)
Ausgezogen am: (Datum) von: (Person)
```

Danach der Text mit den Artikelnummern. Nur die für Funktionäre relevanten Artikel, nicht das ganze Dokument. Das hält die Dateien klein genug für Gratis-KIs.
